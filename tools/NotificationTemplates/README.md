# Notification Template Presets

These JSON files can be imported from `Settings -> Achievement Notification -> Custom style editor -> Import Template`. The same import button can also import a SAN preset folder by selecting that preset's `index.html` or `styles.css`.

The SAN presets embed Steam Achievement Notifier's source HTML/CSS payloads so the source data is preserved. Runtime notifications currently use the WPF compatibility renderer until a true embedded transparent HTML renderer is added.

The HTML template builder also exports `CustomStyleSlot.LayoutStyle`, `CustomStyleSlot.AnimationStyle`, and `CustomStyleSlot.SanPresetId`; use these for SAN-like layouts and transitions such as xQjan, XB Modern, XB Classic, Epic, Aero, and slide/expand card behavior.

The SAN presets are generated by `tools/generate_san_notification_templates.py` from `tools/SAN-source/notify/presets` and the reference video durations in `SAN Videos`; edit the generator first when tuning these templates.

## Steam Achievement Notifier Presets

These presets are based on Steam Achievement Notifier's built-in `notify/presets` set:

- `SAN_Default_Style.json` -> Default
- `SAN_xQjan_Style.json` -> xQjan
- `Steam_Deck_Style.json` -> The Deck
- `Epic_Games_Style.json` -> Epic
- `Xbox_Style.json` -> XB Modern
- `Xbox_Classic_Style.json` -> XB Classic
- `PlayStation_5_Style.json` -> PS Modern
- `SAN_PS_Classic_Style.json` -> PS Classic
- `SAN_PS_Retro_Style.json` -> PS Retro
- `SAN_Square_Style.json` -> Square
- `SAN_Aero_Style.json` -> Aero

Steam Achievement Notifier's `Native OS` preset is not an overlay skin. In this extension, use Windows notification delivery mode for that behavior instead of importing a JSON overlay template.
